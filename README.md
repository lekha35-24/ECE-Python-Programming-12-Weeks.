# ECE Python Programming – 12 Weeks

## About
This repository contains the MCQ and coding files from a 12-week Python programming course for Electronics and Communication Engineering (ECE) students.

## Contents
- **MCQs:** Weekly multiple-choice questions.
- **Coding:** Python programming exercises.
- **Course Duration:** 12 Weeks.

## Purpose
To practice Python programming, improve problem-solving skills, and keep course materials organized for future reference.

**Language:** Python
